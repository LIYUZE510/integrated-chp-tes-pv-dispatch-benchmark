# Repository Guardrails

- Preserve all existing frozen manuscript outputs.
- Never overwrite existing result, report, figure, or table files by default.
- New resubmission outputs must use new tags beginning with `resub_2026_`.
- Do not modify optimization equations merely to obtain preferred results.
- Keep changes minimal and reviewable.
- Add or update tests for every functional change.
- Do not run long optimization experiments unless explicitly requested.
- Use the existing Python 3.11 Conda environment.
- Before completing a task, run the relevant tests and report exact commands and results.
